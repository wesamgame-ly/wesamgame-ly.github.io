# الموسوعة الإلكترونية — MOSGAME

واجهة عربية باللونين الأسود والأصفر للموسوعة الإلكترونية، المتخصصة في صيانة جميع أجهزة PlayStation وXbox. تضم تشغيل Goldhen لأجهزة PlayStation 4 بالأرقام الإنجليزية.

## ملفات التشغيل

حُفظت ملفات المحركات وGoldhen الأصلية دون تعديل: **89 ملفًا من نوع JS وBIN وELF** من [Hazzaz Store](https://github.com/HazzazStore/hazzazstore.github.io)، الإصدار المرجعي `0ab33a34c6f28a769c433029c131dc55b4baee58`.

Goldhen: `v2.4b18.12`. تفاصيل المصدر وإشعاراته في [توثيق المصدر](docs/UPSTREAM.md).

## النشر

الموقع: https://wesamgame-ly.github.io/

موقع ساكن من فرع `main` ومجلد الجذر `/`. جميع روابط الملفات نسبية، وصفحات التخزين تستخدم Application Cache الأصلي لجهاز PlayStation 4.

التصميم المعتمد هو صورة Golden Arabic Console Repair Showcase، مع زر تشغيل فعلي ورسائل حالة ونطاقات إصدارات النظام في HTML. تُحفظ صورة التصميم ضمن ملفات التخزين دون اتصال.

تشغيل الجلبريك والتخزين دون اتصال يتطلبان جهاز PlayStation 4 فعليًا بإصدار مدعوم، ولم يُختبرا على جهاز فعلي في هذه الجلسة.
